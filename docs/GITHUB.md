# GitHub repository setup

## Default branch

To use **`master`** as the default branch for clones and new pull requests:

1. Open [Repository Settings → Branches](https://github.com/abhinavshyju/editer-mcp/settings/branches).
2. Under **Default branch**, choose **master** and confirm.

After switching, you may delete an unused **`main`** branch on GitHub only if nothing still depends on it.
